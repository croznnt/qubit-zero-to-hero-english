# Contributing

1. Keep QuTiP as the sole quantum framework in the core curriculum.
2. Define basis ordering, units, assumptions, and metric conventions for new models.
3. Add an analytic or independently constructed reference for new physics.
4. Preserve raw arrays and metadata; never replace failed runs with selected successful runs.
5. Run `python -m pytest` and the affected CLI experiments before proposing changes.
6. Write learner-facing documentation and explanations in clear English. Preserve code identifiers, mathematical conventions, and source references when revising lessons.
7. Label research extensions as proposals until implemented and validated.
